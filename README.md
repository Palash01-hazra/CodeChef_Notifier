# CodeChef_Notifier

🚀 CodeChef Notifier
CodeChef Notifier is a lightweight Chrome extension that automatically tracks your CodeChef submissions and notifies you as soon as the verdict is available. No more refreshing the page or waiting around—just submit your code and get notified when the result is ready.

🔔 Features
📡 Automatic Submission Tracking: Detects when you make a submission on CodeChef and starts monitoring it.

🖥️ Real-Time Desktop Notifications: Notifies you instantly when your submission result is available.

🧾 Detailed Verdicts: Provides comprehensive information about your submission, including status and error messages.

🧹 Session-Based Caching: Stores submission results for the current browser session.

🔄 Persistent Monitoring: Continues to check for pending submissions even if the browser is closed and reopened.
